# 管理端生图工作台

生图在管理端侧栏的「工具」分组。从桌面工具打开后台时，「视频审核工具」下面就是「生图工作台」。单独打开后台、没有视频工具地址时，这一组只显示生图工作台。

页面沿用现有后台的侧栏、登录和角色。三种角色都可以用，但记录和图片只属于当前登录用户。

## 当前行为

默认是 MOCK 预览：占位图上有 MOCK，不会请求生图接口，也不会扣费。分组名称只读，固定按「生图专用-bot创建」检查当前账号。账号没有这个分组时，按钮不可用，也不会改用审核分组。

可选尺寸和模型以页面上的服务端说明为准。只有 `gpt-image-2.5-flare` 的 `2048x1152` 和 `3840x2160`，并且是 1 张、默认质量，标过上游已验证；本站网关仍待验证。参考图和异步生成首版不可用。

预估费用是张数 × ¥0.10。这是页面上的零售预估。真的扣费以网关账单为准。

## 本地启动

在仓库里检出本分支后：

```bash
cd admin
python -m pip install -r requirements.txt
cd web && npm install && npm run build
cd .. && python run.py
```

本机地址是 `http://127.0.0.1:8780`。这是你自己启动的进程。云端代理如果另开了一个端口，不会替换你电脑上已经开着的 8780。

真实出图要同时设置 `EVC_ADMIN_IMAGE_LIVE=1` 和 `EVC_ADMIN_IMAGE_CONTRACT_OK=1`，并且用已核验的那一组参数。未设置时保持预览。不要把审核密钥或管理密钥配成生图密钥。
