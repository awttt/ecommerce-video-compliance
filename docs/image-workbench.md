# 桌面生图工作台

生图做在现有桌面工具里，本机 `127.0.0.1` 提供页面和接口。不部署到 `admin.token4u.cc`，那个地址只保留管理后台 API。

## 已看到的参考页

`https://chuanapi.com/image` 在已登录状态下能看到浅色工作台，未登录时会进登录页。已核对的控件：

- 居中白卡片，细边框，圆角，深色标题，蓝色主按钮
- 多行提示词，以及 4 条示例
- 模型选择。当时页面写着 No image models available，模型菜单是空的，生成和参考图按钮不可用
- 尺寸：自动、1024×1024、1536×1024、1024×1536，以及方形、横向、纵向
- 张数 1–4，画质为自动且不能改
- 参考图按钮、异步开关、Ctrl/⌘ + Enter
- 结果区有提示词/模型搜索、全部/方形/横向/纵向，以及「还没有历史」空态

没有看到实际生成、上传成功、结果卡片或下载，所以这些不能当成上游已经支持的能力。参考页写的一小时过期、浏览器本地保存和 120 批上限是对方的实现，这里不照搬。

## 公开 API 里能确认的部分

万川公开文档只确认：

- `POST /v1/images/generations` 用于图像生成，具体能力以模型目录为准
- 认证是 `Authorization: Bearer`
- 模型 id 必须来自目录，不能沿用别的平台的名字
- 目录里有声明 `image-generation` 的模型，调用路径是 `/images/generations`

文档没有给出这个端点的请求体字段，模型页上的示例是 Chat Completions，不是生图参数。因此尺寸、张数、画质、参考图和异步开关只留在本机界面，默认不发上游。

## 接入

```text
桌面页面 → 本机 /api/images → 当前登录用户自己的生图密钥 → token4u 生图专用分组
```

- 沿用现在的登录。未登录返回 401。
- 分组名称 `EVC_IMAGE_RELAY_GROUP_NAME`、编号 `EVC_IMAGE_RELAY_GROUP_ID` 只在服务端读取。名称和渠道备注按运维 bot 创建的命名填写，例如「生图专属-bot创建」。两项都空则禁用。
- 前端不能传分组、网关或密钥。网关只允许 `https://token4u.cc/v1`，拒绝 chuanapi 和其他主机，也不走环境代理。
- 生图密钥名叫「御镜生图」，只绑定专用分组。审核密钥「电商视频合规」和审核分组不读、不改。解析到审核分组时直接拒绝。
- 计费用这个用户自己的密钥。没有共享上游密钥，预览模式也不拿预览令牌去调用。
- `EVC_IMAGE_PROVIDER` 留空时禁用。`mock` 只在本机画标识图。`token4u` 在契约对象确认之前仍然拒绝调用，不会先打到上游再失败。

契约由测试注入。生产代码里的默认契约是未确认，没有响应解析器，因此不会发出付费请求。运维确认字段和响应格式之后，再打开这一层。

## 本机记录

提示词、尺寸、张数和参考图记在本机 SQLite，文件放在数据目录的 `image-workbench/<批次编号>/` 下，不使用用户提供的路径。列表、预览、下载和删除都按当前登录邮箱隔离。参考图只接受 PNG、JPEG、WebP，单张最多 4MB，最多 4 张。每个账号最多保留 120 批已完成记录。同一账号有任务进行时，重复提交会拒绝。

预览图上写着 MOCK PREVIEW / NOT UPSTREAM，界面也标明「预览模拟，不是真实上游生图」。
